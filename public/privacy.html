PeopleLens 隐私政策

最后更新：2026-06-07

我们收集什么

PeopleLens 不需要账号，不收集完整浏览历史。用户主动粘贴或通过扩展主动分析的文章内容只用于生成当前页面的人物卡片。

AI 分析

当用户填写 API Key 并主动开始分析时，PeopleLens 会把文章标题、来源 URL 和分句后的正文发送给用户配置的 AI 服务商。API Key 保存在当前浏览器或扩展本地。

本地记忆

PeopleLens 使用浏览器本地存储记录已见过和已保存的人物、遇见次数、时间和来源标题。用户可以在应用内导出或清空这些数据。

Chrome Extension

扩展只在用户点击“分析当前页面”后读取当前活动标签页内容。扩展不做后台扫描，不请求宽泛页面读取权限。AI 请求仅发送到扩展声明支持的服务商 API 域名。

数据删除

用户可以在 PeopleLens 中点击“清空记忆”删除本地 PeopleLens 记忆。也可以通过浏览器站点数据设置清除相关本地存储。
